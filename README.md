# 🧬 DNA Data Storage Demo

A simple Streamlit demonstration for a presentation on:

**DNA as Data Storage – Can We Store the Internet in DNA?**

## What it demonstrates

Text → Binary → DNA sequence → Binary → Original text

### Encoding used

- `00 → A`
- `01 → C`
- `10 → G`
- `11 → T`

This is a simplified educational demonstration. Real DNA data storage involves DNA synthesis, sequencing, error correction, indexing, and laboratory processes.

## Run locally

Open a terminal in this folder and run:

```bash
pip install -r requirements.txt
streamlit run app.py
```

Then open the local Streamlit URL shown in the terminal.

## Best presentation message

Use:

`KRCE PRESENTATION DAY`

Then show the transformation live from text to binary to DNA and back again.
